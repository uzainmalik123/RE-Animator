# R0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Reanimator a pinned Vite + React + TS app skeleton with a blank `--void` canvas page, a Hono backend entry, and a green `npm run health` locally and in CI.

**Architecture:** One standalone npm package at `reanimator/` (not a workspace of Poltergeist). `src/` is the Vite/React UI (one full-viewport canvas); `server/` is a Hono app (`createApp()`) started by `server/main.ts` on 127.0.0.1:7070, with Vite proxying `/api` to it. Two tsconfigs (DOM/bundler for `src/`, NodeNext for `server/` + configs); Vitest in the node environment.

**Tech Stack:** TypeScript 5.9.3, Vite 8.3.5, React 19.3.1, Hono 4.13.16 + @hono/node-server 2.1.5, Vitest 4.1.12, ESLint 9.39.1.

**Spec:** `reanimator/docs/PRD.md` § R0; `reanimator/docs/STACK.md`; `reanimator/docs/THEME.md` §4, §9; grill decisions Q1–Q12 (recorded as D-R12).

## Global Constraints

- Node ≥ 22, ESM (`"type": "module"`), `"private": true`.
- Exact pins (no `^`/`~`): typescript 5.9.3, vitest 4.1.12, eslint 9.39.1, @eslint/js 9.39.1, typescript-eslint 8.72.1, @types/node 22.20.5, tsx 4.23.15, vite 8.3.5, react 19.3.1, react-dom 19.3.1, @types/react 19.3.0, @types/react-dom 19.3.0, @vitejs/plugin-react 6.2.1, hono 4.13.16, @hono/node-server 2.1.5, eslint-plugin-react-hooks 7.1.1, globals 17.14.0.
- Ports: Vite 5173 (strictPort), backend 7070, bound to `127.0.0.1` only. Never 4000/6660/6661 (Poltergeist's).
- Palette tokens verbatim from THEME §4: `--void #06060a`, `--bone #cfc8b8`, `--dim #5d6470`, `--magic #b98cff`, `--death #ff3b4e`, `--rot #8fb26b`.
- Fresh code only (D-R2). No art, no scenes (R1+).
- `npm run health` = `typecheck && lint && test`.

## Review Focus

1. **Backend reachable from the LAN** — the server must listen on `127.0.0.1`, not `0.0.0.0`; `main.ts` passes `hostname: '127.0.0.1'` (checked by reading `main.ts`; the bind isn't unit-tested).
2. **Unknown `/api/*` path** — should 404 JSON-free default, not crash; test `GET /api/nope` → 404 in Task 2.
3. **High-DPI screens / window resize** — canvas must be sized `innerWidth*devicePixelRatio` and redrawn on resize; `sizeCanvas` is pure and tested with dpr 2 in Task 1.
4. **CI on a clean checkout** — `npm ci` needs a committed `reanimator/package-lock.json`; Task 3 verifies `npm ci && npm run health` from scratch.
5. **Lint sweeping docs/plans or dist** — eslint ignores `dist/`, `node_modules/`, `coverage/`.
