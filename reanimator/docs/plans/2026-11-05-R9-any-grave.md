# R9 Any Grave (GitHub URL, real clone & revive) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The user pastes a dead repo's GitHub URL; the backend clones it, proves it dead, applies the fixed rites that fit, and raises it on real vitals, every untrusted command inside a bubblewrap sandbox.

**Architecture:** A ritual's fixture factory now takes the request and the ritual's work dir. No URL = the practice corpse as before. A URL = a *grave fixture*: cloned into the work dir (`server/grave.ts`), its remedy is `applyRites` (`server/rites.ts`), its serve argv is inferred (`server/serve.ts`, with our own `static-serve.mjs`), and it carries a `sandbox` that wraps every vital's argv in `bwrap` (`server/sandbox.ts`). Vitals, the re-raise (R5), the grimoire (R7) and the recorder (R11) keep working through the same `Fixture`.

**Tech Stack:** TypeScript, Node 22+, Hono, React 19, Vitest; `git` and `bwrap` (bubblewrap) on the host. No new npm dependencies.

**Spec:** the R9 grill (Q1–Q11, recorded as D-R23) and `docs/PRD.md` R9.

## Global Constraints

- URLs: only `https://github.com/<owner>/<repo>` with optional `.git` or trailing `/`; owner `[A-Za-z0-9-]{1,39}`, repo `[A-Za-z0-9._-]{1,100}`, repo not `.` or `..`. Anything else → `400 {error: 'repo must be https://github.com/<owner>/<repo>'}`.
- Clone argv: `git -c core.hooksPath=/dev/null clone --depth 1 --no-recurse-submodules --single-branch -- <url> <dest>`, env `childEnv` + `GIT_TERMINAL_PROMPT=0`, timeout 60 000 ms. Size cap 100 MB (`104_857_600` bytes, files under dest excluding `.git`).
- Headstone: name `<owner>/<repo>`; `diedIn` = year of the last commit (`git log -1 --format=%cd --date=format:%Y`); licence = `package.json` `license` string, else `'unknown'`.
- Sandbox (`bwrap`): ro-bind `/usr`; ro-bind-try `/bin /lib /lib64 /sbin /etc/resolv.conf /etc/hosts /etc/nsswitch.conf /etc/ssl /etc/ca-certificates /etc/pki`; `--proc /proc --dev /dev --tmpfs /tmp`; rw-bind the ritual work dir at its own path; ro-bind `static-serve.mjs` at its own path; `--unshare-all --share-net --die-with-parent --chdir <cwd>`. Env inside: only `PATH=/usr/local/bin:/usr/bin:/bin`, `HOME=<workdir>/home`, `LANG=C.UTF-8`, plus `PORT`/`HOST` for serve. No secrets, no `npm_config_*`.
- No `bwrap` (or it fails to run `true`) → the ritual fails: `no sandbox: install bubblewrap (bwrap) to raise a stranger's repo`. Prepared fixtures stay unsandboxed.
- Rites, in this order, names verbatim: `engines` (only when `engineStrict: true` in package.json or `engine-strict=true` in `.npmrc`: drop `engines.node`, `engineStrict`, the `.npmrc` line), `node-sass` (dep or devDep → removed, `sass: "^1.77.0"` added in the same section), `openssl` (`webpack` or `react-scripts` in deps/devDeps whose range's first number is < 5 → `.npmrc` `node-options=--openssl-legacy-provider`), `lockfile` (`package-lock.json` with `lockfileVersion` missing or 1 → deleted, `.npmrc` `legacy-peer-deps=true`).
- No rite fits → `failed` (phase `revived`), verbatim `no rite fits this death`.
- Serve inference: `scripts.start` → `['npm', 'start']`; else the first of `dist`, `build`, `public`, `.` holding `index.html` → `['node', STATIC_SERVE, <abs dir>]`; else serve fails: `no way to serve it: no start script and no index.html`.
- A grave has no chart → `POST /api/rituals/:id/attack` = `409 {error: 'this grave has no chart: Death needs one to attack'}`.
- Not-dead refusal (D-R15) unchanged. Clone/sandbox failure → `failed` phase `corpse`, reason prefixed `clone: ` (or the no-sandbox line).
- Nothing faked (D-R11). R6 (graveyard) is not built: one plain text field only.
- `npm run health` green after every task.

## Review Focus

- A URL with a query/hash or `http://` or `github.com.evil.com` → 400, never cloned (test in Task 1).
- A repo with no `package.json` → rites apply none (no throw); headstone licence `unknown` (tests in Tasks 1, 2).
- `static-serve.mjs` asked for `/../../etc/passwd` → 404, never outside its root (test in Task 3).
- A new ritual while a clone is running → the clone's git group is killed via the abort signal (test in Task 4).
- A malformed `package.json` in the clone → rites report none and the corpse's install fails honestly (test in Task 2).
