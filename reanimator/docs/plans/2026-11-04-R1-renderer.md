# R1 Dot-matrix Renderer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One reusable renderer that turns any image (or live frame) into Bayer-dithered dots or glyphs on a canvas, shown on a demo page in purple on void.

**Architecture:** `src/render/` splits a **pure core** (luminance grid → dither levels, runs in Vitest's node env and is snapshot-tested) from **thin canvas painters** (`drawDots`, `drawGlyphs`, and a `DotRenderer` that caches levels and repaints only changed cells). `App.tsx` becomes the R1 demo: the stage canvas renders our own SVG sample, with a real-text control panel for pitch and mode.

**Tech Stack:** TypeScript 5.9.3, React 19.3.1, Canvas 2D (no library), Vitest 4.1.12 (node env).

**Spec:** `reanimator/docs/THEME.md` §3, §4, §7, §9; `reanimator/docs/PRD.md` § R1; `.kiro/specs/reanimator/requirements.md` Req 4.1, 4.3, 4.4; `design.md` §5; grill Q1–Q15 (recorded as D-R13).

## Global Constraints

- Fresh code and fresh assets only (D-R2). The sample image is hand-written SVG in this repo.
- Palette tokens are exactly THEME §4: `--void #06060a`, `--magic #b98cff` (the demo ink), the rest unchanged.
- `BAYER4 = [0,8,2,10, 12,4,14,6, 3,11,1,9, 15,7,13,5]`, threshold `(v + 0.5) / 16`.
- Luminance is Rec. 709 `0.2126R + 0.7152G + 0.0722B` on 0–1 channels, then gamma 1.2 (`lum ** 1.2`).
- Level 0 is always empty (draws nothing). Default `steps` is 4 for dots. Glyph ramp is `" .:-=+*#%@"`, with steps equal to the ramp length.
- Deterministic: the same luminance grid and options always give the same levels and the same draw calls.
- Pitch is in CSS px: 2 when the viewport is under 640 CSS px wide, otherwise 3. The backing store is CSS size × DPR.
- Real text stays real text: the control panel is HTML, never drawn into the canvas.
- `prefers-reduced-motion: reduce` means no animation loop (one static frame).
- `npm run health` stays green.

## Review Focus

1. **Empty or zero-size canvas** (hidden tab, 0×0 layout): rendering must no-op, not throw or divide by zero. Task 1 tests `gridSize(0, 0, 3)` → `{cols: 0, rows: 0}` and `ditherLevels` of an empty grid.
2. **Pitch changes mid-animation**: the cache must reset when the grid size changes, or old cells get diffed against a wrong layout. Task 3 tests that a new grid size repaints every lit cell.
3. **Out-of-range luminance** (above 1 from a bad sample, or NaN): levels must clamp to `[0, steps-1]`, and NaN must count as dark. Task 1 tests this.
4. **A DPR-only change** (moving to another monitor) must resize (KI-R11). Task 4 listens to `matchMedia('(resolution: Xdppx)')`. It isn't unit-tested (it needs a DOM), so check it by reading the code.
5. **Image not yet loaded**: the first paint happens before the SVG decodes. Task 4 renders only after `img.decode()` resolves.

### Task 1: Pure dither core

**Files:**
- Create: `reanimator/src/render/dither.ts`
- Test: `reanimator/src/render/dither.test.ts`

**Interfaces:**
- Produces:
  - `BAYER4: readonly number[]`
  - `GLYPH_RAMP = ' .:-=+*#%@'`
  - `gridSize(width: number, height: number, pitch: number): { cols: number; rows: number }`, using `Math.floor`, and 0 for non-positive or non-finite input
  - `luminanceGrid(rgba: Uint8ClampedArray, cols: number, rows: number, gamma?: number /*1.2*/): Float32Array`, where alpha multiplies brightness (transparent = dark)
  - `ditherLevels(lum: Float32Array, cols: number, rows: number, steps: number): Uint8Array`
  - `levelsToText(levels: Uint8Array, cols: number, ramp?: string): string`, with rows joined by `\n` and level i mapped to `ramp[i]` (the test helper and the glyph source)

- [ ] **Step 1: Write failing tests.** `dither.test.ts`:
  - `gridSize(800, 600, 3)` → `{cols: 266, rows: 200}`; `gridSize(0, 0, 3)` and `gridSize(10, 10, 0)` → zeros.
  - `luminanceGrid` of pure white opaque → `1`; black → `0`; white at alpha 0 → `0`; mid-grey 128 with gamma 1 → ≈ `0.502`.
  - `ditherLevels` of all-0 → all 0; all-1 at steps 4 → all 3; values `[2, -1, NaN]` clamp to `[3, 0, 0]`.
  - Uniform lum 0.5 at steps 2 over 4×4 → exactly 8 lit cells (ordered dither halves the cells), and the same result on a second call (determinism).
  - Snapshot: a 16×8 horizontal gradient (`lum = col/15`) at steps 10, through `levelsToText(…, GLYPH_RAMP)`, matches `toMatchInlineSnapshot()`. Pin whatever the first green run writes, after eyeballing that it goes dark → light from left to right.

- [ ] **Step 3: Implement.** The algorithm is fixed:

```ts
const t = (BAYER4[(row & 3) * 4 + (col & 3)]! + 0.5) / 16;
const v = Number.isFinite(l) ? Math.min(Math.max(l, 0), 1) : 0;
level = Math.min(steps - 1, Math.floor(v * (steps - 1) + t));
```

### Task 2: Canvas painters (`drawDots`, `drawGlyphs`, `sampleLuminance`)

**Files:**
- Create: `reanimator/src/render/draw.ts`
- Test: `reanimator/src/render/draw.test.ts`

**Interfaces:**
- Consumes: Task 1.
- Produces:
  - `type Palette = { ink: string; background?: string }`
  - `type DotOptions = { pitch: number; palette: Palette; steps?: number /*4*/; gap?: number /*1*/; shape?: 'circle' | 'square'; scale?: number /*dpr, 1*/ }`
  - `type GlyphOptions = Omit<DotOptions, 'shape' | 'gap' | 'steps'> & { ramp?: string; font?: string /*'JetBrains Mono', monospace*/ }`
  - `type Ctx = Pick<CanvasRenderingContext2D, 'fillStyle' | 'fillRect' | 'beginPath' | 'arc' | 'fill' | 'fillText' | 'font' | 'textAlign' | 'textBaseline' | 'clearRect'>`
  - `paintDot(ctx: Ctx, col: number, row: number, level: number, o: Required<…>)`, which paints one cell (used by Task 3)
  - `drawLevelsAsDots(ctx: Ctx, levels: Uint8Array, cols: number, rows: number, o: DotOptions): number`, which returns the dots drawn
  - `drawLevelsAsGlyphs(ctx: Ctx, levels: Uint8Array, cols: number, rows: number, o: GlyphOptions): number`
  - `sampleLuminance(image: CanvasImageSource, cols: number, rows: number): Float32Array`, which uses an `OffscreenCanvas(cols, rows)` (or `document.createElement('canvas')`) with `drawImage` scaled down, then `getImageData` → `luminanceGrid` (browser only, not unit-tested)
  - `drawDots(ctx, image, o: DotOptions): number` and `drawGlyphs(ctx, image, o: GlyphOptions): number`, which work out the grid from `ctx.canvas` size / (pitch·scale), sample, dither and paint
- The dot radius in device px is `((pitch − gap) / 2) · (0.4 + 0.6 · level / (steps − 1)) · scale`, centred in the cell. A square uses the same half-size. Background (if set) fills first; otherwise `clearRect`.
- Glyphs: font size `pitch·scale` px, `textAlign 'center'`, `textBaseline 'middle'`, char `ramp[level]`, and level 0 skipped.

- [ ] **Step 1: Write failing tests** with a recording fake ctx (an object whose methods push `[name, ...args]` into an array):
  - `drawLevelsAsDots` on the levels `[0,3,1,0]` (2×2), pitch 3, gap 1 → returns 2 and records exactly 2 `arc` calls. The first arc's centre is `(4.5, 1.5)`, with radius `1 · 1.0 = 1`.
  - The same levels at `shape: 'square'` → 2 `fillRect` calls after the background and no `arc`.
  - Changing pitch changes density: lum all 0.6 over a 60×60 px area, with grids from `gridSize(60, 60, 2)` vs `gridSize(60, 60, 6)` → the dot count at pitch 2 is greater than at pitch 6.
  - `drawLevelsAsGlyphs` records `fillText` calls with chars from the ramp and never a space.
  - Determinism: two runs on the same input give an identical call log (`toEqual`).

### Task 3: `DotRenderer` (cache and changed-cells-only)

**Files:**
- Create: `reanimator/src/render/renderer.ts`, `reanimator/src/render/index.ts` (re-exports of Tasks 1–3)
- Test: `reanimator/src/render/renderer.test.ts`

**Interfaces:**
- Consumes: Tasks 1–2.
- Produces: `class DotRenderer { constructor(ctx: Ctx, o: DotOptions); renderLuminance(lum: Float32Array, cols: number, rows: number): number /* cells repainted */; render(image: CanvasImageSource): number; reset(): void }`
- Behaviour: on the first frame, after `reset()`, or when `cols`/`rows` change, it paints the background and every lit cell, and returns that count. On later frames it diffs against the previous `Uint8Array`. For each changed cell it clears that cell's square (background fill, or `clearRect`) and paints the new level if > 0. It returns the number of changed cells.

  - Change one cell to 0 → returns 1, with one cell clear and no arc.
  - A new grid size (5×4) → repaints every lit cell (returns 20 for all-1).
